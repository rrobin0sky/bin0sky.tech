1.1 大模型对话底层认知与吴恩达核心铁律

🎯概率预测与注意力机制

LLM 本质是根据前文预测下一个 Token 的概率分布。不清晰的 Prompt 会导致概率空间极度发散（产生泛化、空洞的“AI 塑料味”废话）；具体的限定词、场景与格式则是在收敛注意力范围，迫使输出精准命中专业空间。

⚖️吴恩达两大核心铁律

  1. 原则一：表达明确且具体的指令（使用分隔符区分指令与输入内容、指定结构化输出格式、设定边界条件与检验机制）。
  2. 原则二：给予模型“思考”的时间（指定完成任务所需步骤、指导模型在仓促得出结论前自行推导解决方案）。
1.2 三大主流工业级结构化框架

框架 ①：ICDO 极简生产公式

日常高频推荐

适用于绝大多数任务型需求，结构清晰紧凑：

I
Instruction（核心指令）：你要模型执行的动作（如“编写代码”、“提取核心要点”）。
C
Context（角色与背景）：模型的专业身份、目标受众、使用场景。
D
Data / Input（输入数据）：原始资料、代码片段、待处理文本（建议用 """ 或 ``` 包裹）。
O
Output（输出规范）：排版格式（Markdown/JSON/Mermaid）、字数范围、语气风格、负向约束。

框架 ②：CRISPE 角色执行框架

复杂职场咨询

适合复杂职场与专业角色咨询：

CR
Capacity & Role（能力与角色）：你希望模型扮演谁（如资深架构师、法务顾问）。
I
Insight（背景洞察）：业务背景、技术栈限制、现有困境。
S
Statement（陈述要求）：任务的具体指标与期望达成的目标。
P
Personality（风格语气）：语言风格（严谨犀利、通俗风趣、中立客观）。
E
Experiment（尝试范围）：提供多套方案、或限制在某种固定策略内。

框架 ③：CO-STAR 全要素框架

企业级交付

适用于高质量公文、品牌方案、营销策划等企业级交付：

C
Context（背景）：提供详实的任务场景与上下文。
O
Objective（目标）：界定交付成果需要解决的核心问题。
S
Style（写作风格）：指定某知名作者、商业期刊或公文行文风格。
T
Tone（情感基调）：热情、严肃、敬畏、说服力强。
A
Audience（目标受众）：受众认知水平（如非技术高管、初中生、资深极客）。
R
Response（响应规范）：表格、层级列表、代码块、字数等具体呈现形式。
⚡ 选型决策速查：按任务特征快速定位推荐框架
1.3 高阶控制技术精要（Ibrahim John 指南与前沿技术）
技术名称 核心原理 适用场景与提示技巧
Few-Shot（少样本学习） 提供 1~3 个标准“输入-输出”成对样例，为模型建立格式与逻辑基准 提取复杂信息、定制化 JSON 输出、特定风格文案生成
CoT（思维链，Chain-of-Thought） 显式要求模型“逐步思考（Step by Step）”，将隐式推理外化 数学推导、业务逻辑审计、代码 Bug 根因分析
Self-Consistency（自我一致性/自洽提示） 要求模型生成多条路径并进行交叉核验，消除前后矛盾与幻觉 数据核查、事实校验、法务合约审核
Adversarial Prompting（对抗提示） 主动设定反向挑刺与边界测试，迫使模型识别漏洞 架构评审、辩论立论加固、安全防御策略演练
Curriculum Learning（课程学习渐进法） 从简单任务逐步过渡到复杂任务，多轮分阶段推进 长篇网文/图书大纲与章节写作、大型系统重构

从单次 Prompt 到 Agent 智能体的认知跃迁

        
AI 生产力的演进路径：从零散对话逐步升级为结构化指令、多轮任务编排与自主反思的智能体闭环。

      

    


    

      

        

          LEVEL 1 · AD-HOC
          
零散提问

          
随手输入一句话，概率空间极度发散，只能得到泛化的普通回答。

        

        

          LEVEL 2 · ENGINEERED
          
结构化 Prompt

          
应用 ICDO / CRISPE 框架，通过约束角色、数据与格式协议，输出标准交付物。

        

        

          LEVEL 3 · CHAINING
          
多轮任务流

          
大纲 ➔ 分段 ➔ 审查 ➔ 改写，将复杂问题拆解为多步确定性流水线推进。

        

        

          LEVEL 4 · AGENTIC LOOP
          
自主智能体

          
角色定义 + 工具系统（MCP / CLI），实现自主观察、反思、修正与端到端交付（ReAct）。

        

      


      

        

          
Prompt 是 Agent 的灵魂

          
智能体（Agent）的 System Prompt，本质上就是最高规格的结构化提示词（明确角色能力边界、工具调用触发时机、格式协议与容错恢复机制）。

        

        

          
心法 01：拒绝一次性包办

          
不要指望一次提示完成所有宏大任务；单次上下文承载过多目标会导致模型注意力稀释、细节丢失。

        

        

          
心法 02：任务分阶段拆解 (Decomposition)

          
复杂的任务按“规划大纲 → 逐段生成 → 交叉校验”分阶段推进，每一步的中间产物都可以作为下一步的高质量上下文。

        

        

          
心法 03：样本对齐与自我反思

          
善用示例（Few-Shot）指明输出规范，善用反思（Self-Reflection）机制要求模型自查逻辑漏洞与事实偏差，把控最终交付质量。
